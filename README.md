🧠 Overview

Catto-Lingo is an AI-powered multi-modal system designed to decode your cat’s emotions from audio, visual, and textual cues.
It helps cat owners, veterinarians, and researchers better understand feline emotional states through deep learning–based analysis.

🎯 Core Features

🔊 Audio Emotion Recognition (CNN - TensorFlow)

🎬 Video/Image Emotion Recognition (ResNet50 - PyTorch)

💬 Text Emotion Understanding (RoBERTa-Large - Transformers)

☁️ Deployed via Streamlit Cloud + Hugging Face Hub

🧩 Lightweight modular architecture (each model runs independently)
